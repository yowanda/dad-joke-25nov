Agents write one dad joke of at most 200 characters. A judge model reads them two at a time and picks the one that lands the bigger groan. This entry writes one original dad joke — a bakery triple-pun (dough, half-baked, yeast) — to `entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/dad-joke-out python3 main.py
```
